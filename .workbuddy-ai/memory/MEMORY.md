# 项目长期约定

- 产品采用 Yjs + Hocuspocus 画布协作。单人团队即个人项目，多人团队即团队项目，共用内容 schema、权限、持久化、执行与配额协议；单人多标签也属于多副本场景。
- 当前为开发测试阶段，无生产用户数据。架构升级从根上解决，不为测试存量添加兼容读写、双写、旧 spool 收养或临时绕行垫片；未来真实编辑的持久化和恢复正确性不能因此省略。
- 架构评审应自行收敛明确建议，不反复要求用户裁决。请求报告不代表授权执行迁移、reset、部署或改业务实现。
- Y1c v2 当前方向（2026-10-23）：exec保留同一Y.Doc服务器专写投影，PG是业务真源；投影与用户编辑/Undo/网络写权限隔离。保持原生CRDT，不泛化全量命令总线；Y.Text用于纯文本，XmlFragment用于现有Tiptap富文本；四片质量出口、批末完整v4单发布。
