# Spec: 图片标注功能 (Image Annotation)

> 状态: 待确认  
> 日期: 2026-06-28

## 1. 功能概述

图片标注功能让用户在 Canvas 画布的图片节点上直接绘制标注（画笔、矩形、直线），标注内容叠加在图片上方。保存后**新建一个图片节点加载标注合成图，并与原图片节点自动连线**，原节点保持不变。

**参考模式：** 擦除（Erase）功能 —— 相同的 editMode 状态管理模式、Canvas 叠加层模式、工具栏切换模式。

## 2. 入口

Canvas 页面中，图片节点上方悬浮工具栏（ImageNodeToolbar）第一行的「标注」按钮（已存在 EditOutlined 图标和"标注"文字，当前无 onClick）。

点击后进入标注编辑模式（`editMode: 'annotate'`），悬浮工具栏替换为标注专用工具栏。

## 3. UI 布局（标注模式）

### 3.1 标注工具栏（图片节点上方）

替换 ImageNodeToolbar，显示标注专用工具栏，包含：

| 区域 | 内容 |
|------|------|
| 退出标注 | 按钮，文字「标注」+ 返回箭头图标，点击触发退出（有未保存内容时弹确认窗） |
| 绘制工具 | 画笔（默认选中）、矩形、直线 — 三个图标按钮，单选切换，选中态高亮 |
| 分隔线 | |
| 颜色选择 | 圆形颜色指示器 + 6 个预设色块（黑、白、红、黄、蓝、绿），默认红色 #FF0000 |
| 线宽调节 | 滑块 1-40px，默认 4px |
| 分隔线 | |
| 撤销/重做 | 两个按钮，重做在无历史时 disabled |
| 保存 | 白色按钮「保存」，合成标注+原图 → 上传 → 创建新节点+连线 |

布局参考：
```
[← 标注] | [画笔] [矩形] [直线] | [预设色块] [●自定义] [━━━●━━━] | [↩] [↪] | [保存]
```

**窄节点适配：** 当图片节点宽度 < 工具栏最小宽度（360px）时，工具栏居中悬浮、允许超出节点范围，弹出层挂载到 `document.body`。

### 3.2 标注画布（双 Canvas 架构）

#### 显示层 Canvas（交互用）
- DOM 尺寸与图片节点的 CSS 显示尺寸完全一致
- 适配 `devicePixelRatio` 做高清渲染
- 仅负责鼠标交互与实时绘制预览
- 统一使用 PointerEvent，兼容鼠标、触控笔、触摸设备

#### 离屏层 Canvas（合成用）
- 像素尺寸与原图物理分辨率 1:1 对齐
- 所有绘制操作按比例系数同步映射
- 最终合成时作为标注层与原图叠加，输出原分辨率 PNG

#### 坐标换算公式
```
scale = 原图宽度 / 节点显示宽度
离屏绘制坐标 = 鼠标显示坐标 × scale
离屏线宽 = 显示线宽 × scale
```

### 3.3 无底部工具栏

标注功能不涉及 AI 生成，不需要 EraseBottomToolbar 式的底部工具栏（无模型选择、比例、生成按钮）。

## 4. 绘制工具

### 4.1 画笔（默认工具）
- 自由绘制路径
- 颜色和线宽由工具栏设置控制
- 基于 `PointerEvent.pressure` 实现压感：鼠标压力固定 0.5，触控笔动态调整线宽

### 4.2 矩形
- 拖拽绘制矩形
- 仅描边（不填充），颜色和线宽由工具栏设置控制

### 4.3 直线
- 拖拽绘制直线段
- 颜色和线宽由工具栏设置控制

## 5. 交互行为

### 5.1 进入标注模式
- 点击「标注」按钮 → `editMode = 'annotate'`
- 节点锁定不可拖拽（同擦除模式）
- 画布锁定不可平移/缩放（同擦除模式；锁定口径=节点编辑中**或 transform 旋转/镜像调整中**——2026-09-28 交互重构 spec §3 根因修，与 useGroupKeyboard「模式中」对齐；空格平移旁路已收窄 panActivationKeyCode=null，节点/边内部中键拖由 wrapper 闸门封死〔六修〕，Ctrl+滚轮缩放旁路登记存在）
- 禁用图片节点的缩放手柄，防止标注画布与图片错位
- 初始化标注状态到 nodeStore（工具、颜色、线宽、历史栈）

### 5.2 退出标注模式（分层处理）

#### 有未保存内容
- 弹出 Ant Design 确认弹窗（Modal.confirm），防止误操作丢失
- 确认后丢弃标注内容，清空 nodeStore 标注状态，恢复节点可拖拽/缩放

#### 无未保存内容
- 直接退出，清空状态

#### ESC 键分级处理
- 绘制过程中（鼠标按下未抬起）按 ESC → 取消当前正在绘制的图形，不写入历史，不退出模式
- 空闲状态按 ESC → 触发退出逻辑，走未保存确认

#### 点击外部判定时机
- 仅在 `mouseup` / `touchend` 时判定点击目标是否在标注节点外
- 拖拽过程中指针移出节点不触发退出，避免误中断

### 5.3 保存标注（新建节点 + 连线）
- 将离屏 Canvas（原图分辨率）标注内容与原图合成为一张新 PNG
- 输出格式：PNG（保证标注半透明效果正确），文件名追加 `_annotated` 后缀
- 上传合成图片到 MinIO → 获取新 fileId
- 调用 `canvasStore.addChildNode(sourceId, { fileId: newFileId, status: 'done' })` 在原节点右侧创建新图片节点，自动连线
- 保存成功后退出标注模式，清空历史栈
- **Loading 防护：** 保存中全工具栏置灰禁用，防止重复提交。上传/创建失败时保留标注内容，弹出错误提示并支持重试

## 6. 撤销/重做

- 历史栈上限 50 步，超出后自动丢弃最早操作
- 撤销：移除最后一个绘制操作（笔画/形状），恢复时重绘剩余历史
- 重做：恢复最近被撤销的操作
- 快捷键：`Ctrl/Cmd + Z` 撤销，`Ctrl/Cmd + Shift + Z` / `Ctrl/Cmd + Y` 重做
- 保存成功后，清空历史栈与重做栈

## 7. 绘制交互细节

- **工具切换：** 绘制过程中切换工具，自动取消当前未完成的绘制，不写入历史栈
- **参数生效范围：** 颜色、线宽修改仅对后续新绘制的图形生效，不回溯修改已完成的标注
- **触控事件阻断：** 标注 Canvas 阻止 touchstart/touchmove 事件冒泡，避免触发画布原生平移/缩放/框选手势（2026-09-28 交互重构后空白拖=框选）
- **压感支持：** 基于 `PointerEvent.pressure`，鼠标固定 0.5，触控笔动态

## 8. 状态管理

### 8.1 nodeStore 扩展
- `ImageNodeData.editMode` 联合类型增加 `'annotate'`
- 复用现有 `activeEditNodeId`、`triggerCancelEdit`、`setEditOverlayDragging`

### 8.2 标注临时状态（存入 nodeStore，非组件内部 state）
**原因：** React Flow 视口虚拟化会在节点移出视口时卸载组件，组件内部 state 会丢失。

以 `activeEditNodeId` 为 key 存储：
```ts
annotationState: {
  tool: 'pen' | 'rect' | 'line';
  color: string;
  lineWidth: number;
  history: DrawOp[];       // 绘制历史栈（最多 50）
  redoStack: DrawOp[];     // 重做栈
}
```
- 进入标注模式时初始化
- 保存/退出模式时清空
- 节点重渲染、视口滚动后可完整恢复

## 9. 跨域画布污染防护

- 图片标签强制设置 `crossOrigin="anonymous"`
- 进入标注模式前校验图片 complete 状态，加载失败则禁用标注按钮并提示
- 若 `toBlob` 调用因跨域失败，捕获 SecurityError 并提示用户

## 10. 技术方案摘要

| 项目 | 方案 |
|------|------|
| 显示画布 | AnnotationCanvas 组件，devicePixelRatio 高清渲染 |
| 离屏画布 | OffscreenCanvas（或内存 Canvas），原图分辨率 1:1 |
| 工具栏 | 新建 AnnotationToolbar 组件（独立于 EditToolbar） |
| 合成 | 离屏 Canvas + 原图 drawImage → toBlob('image/png') |
| 上传 | presigned URL 上传合成图，文件名追加 `_annotated` |
| 创建节点 | `canvasStore.addChildNode(id, { fileId, status: 'done' })` |
| 退出模式 | `updateConfig(id, { editMode: null })` + `setActiveEditNodeId(null)` |
| 状态持久 | nodeStore.annotationState（防虚拟化卸载丢失） |

## 11. 风险与边界场景

| 场景 | 风险等级 | 处理方案 |
|------|----------|----------|
| 超大原图（>8K 分辨率） | 中 | Canvas 最大尺寸限制（Chrome ~16384px），超出时等比压缩至安全尺寸再合成，保存时给出轻量提示 |
| 原图加载失败 | 低 | 进入标注模式前校验图片 complete 状态，加载失败则禁用标注按钮并提示 |
| 高 DPI 屏幕预览模糊 | 低 | 显示层 Canvas 按 devicePixelRatio 放大画布尺寸，绘制时缩放上下文 |
| 频繁绘制内存占用 | 低 | 历史栈上限 50 + 退出模式强制清理离屏画布与数组引用 |
| 保存失败 | 低 | 保留标注内容，弹出错误提示，支持重试 |

## 12. 不包含（本期不做）

- 文字标注工具
- 填充形状（仅描边）
- AI 辅助标注
- 标注数据持久化（保存为矢量图层）
- 多人协作标注
- 标注样式模板/预设
- JPG 原图格式适配（统一输出 PNG）
