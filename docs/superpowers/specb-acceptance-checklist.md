# Spec B 需求 5/6/7 用户可见验收清单（B7-2 交付物——v3.17 终裁 68⑤）

口径：**非实现者可判**的「打开画布→操作→看到什么」半小时人工判定表。判定环境：本地双浏览器
（或双标签页登录两个测试账号 collab-a / collab-b）。
每项结论三档：✅ 通过 / ❌ 不通过（阻断）/ ⚠️ 与登记风险相符（引用风险台账编号，见 specb-risk-ledger.md）。

## 准备（约 5 分钟）

1. 启动本地服务（api+web），用 collab-a 登录浏览器 A、collab-b 登录浏览器 B。
2. A 新建画布并打开同一项目（B 经链接或 /works 进入同画布）。
3. 确认两端右上角均为「已连接」。

## 需求 5：组几何（拖拽/折叠/尺寸——约 10 分钟）

| # | 操作（A 端） | 应看到 | 判定 |
|---|--------------|--------|------|
| 5.1 | 加 2 个文本节点→框选→打组 | 出现组框：框内四周留白均匀（左右下约 20px、顶部约 50px 标题带）；B 端 3s 内同步出现同款组 | ✅/❌ |
| 5.2 | 拖组内子节点小位移松手 | 组框随之贴合（无残框/无空框）；B 端位置与 A 逐位一致（肉眼无错位） | ✅/❌ |
| 5.3 | 拖组本身移动 | 组内子节点跟随不变形；松手后 B 端整个组+子到达同位置 | ✅/❌ |
| 5.4 | 拖组中（按住不放）观察 B 端 | B 端组框纹丝不动（拖动过程不下发）——松手后一次跳到终位 | ✅/❌（⚠️ A3 属设计内：无过程动画） |
| 5.5 | 拖最后一个成员出组松手 | 组不解散，收成折叠小卡尺寸（220×160）停在原地；B 端同款 | ✅/❌ |
| 5.6 | 选中组拖右下角 resize 变大 | 框变大、子节点不跑位；Ctrl+Z 一次→只回退其后那次拖动，**组尺寸不回退** | ✅/❌ |
| 5.7 | 折叠组→展开 | 展开 recall 原尺寸原位（manual 组）；B 端同步折叠/展开且子节点显隐一致 | ✅/❌ |
| 5.8 | 拖子节点后立即 Ctrl+Z | 只回退这次拖动（组框回到拖前贴合态）；再 Ctrl+Shift+Z → 位置逐位复原 | ✅/❌ |

## 需求 6：+号输出按钮（多选/组批量连线入口——约 5 分钟）

| # | 操作（A 端） | 应看到 | 判定 |
|---|--------------|--------|------|
| 6.1 | 单选一个普通组 | 组框右缘外侧出现圆形「+」号（距框边约 12px，24px 圆） | ✅/❌ |
| 6.2 | 框选 ≥2 节点 | 选框右缘中点出现同款 +号 | ✅/❌ |
| 6.3 | 按 Ctrl+滚轮 把画布缩到 50%/放到 200% | +号**屏幕尺寸不变**（不随缩放变大变小）、仍贴框右缘 12px、不被组框/节点遮住可点击 | ✅/❌ |
| 6.4 | 折叠组/分镜组选中 | 不出现 +号 | ✅/❌ |
| 6.5 | 从 +号拖线到一个目标节点松手 | 选中集每个源节点到目标各连一条边（N 条边一次生成） | ✅/❌ |
| 6.6 | 从 +号拖线落空（空白处）松手 | 弹出「选类型建节点」菜单而非静默丢弃 | ✅/❌ |
| 6.7 | B 端只读降级（或锁画布） | B 端不出现 +号 | ✅/❌ |

## 需求 7：批量连线/点击建点（约 5 分钟）

| # | 操作 | 应看到 | 判定 |
|---|------|--------|------|
| 7.1 | 多选 3 节点→+号**点击**（不拖） | 弹出类型选择菜单；选「文本」→ 在 +号旁新建节点并自动连线（多源→新节点 N 条边） | ✅/❌ |
| 7.2 | +号拖线落在隐藏节点上 | 不响应（落空同语义：弹建点菜单或无动作，不连到看不见的节点） | ✅/❌ |
| 7.3 | 批量连线后 Ctrl+Z | N 条边一步全撤（单 undo 项）；Ctrl+Shift+Z 一步全恢复 | ✅/❌ |
| 7.4 | 连线落到已有连线两端相同节点 | 不产生重复边（幂等） | ✅/❌ |

## 协作收尾（约 5 分钟）

| # | 操作 | 应看到 | 判定 |
|---|------|--------|------|
| C.1 | A 拖子节点→B 同时拖另一子节点→先后松手 | 两个位移都保留；两端逐位一致 | ✅/❌（⚠️ A1 同节点才 LWW） |
| C.2 | A 拖组→B 改子→A Ctrl+Z | A 的组位移回滚、B 的子位移保留（部分回退） | ✅/❌（⚠️ A2 设计内） |

| C.4 | 断网（DevTools offline）拖动松手→恢复网络 | 重连后 B 端收到离线期间的位移 | ✅/❌ |
| C.5 | 第三浏览器（collab-c）只读打开 | C 能看到 A/B 的一切几何变化，无编辑入口 | ✅/❌ |
