# Spec B 多指/capture 抑制/watchdog 真机验证协议（B7-2 交付物——非 CI）

范围：Playwright 无多指 API、jsdom 无触摸布局——以下手势面**只能真机（触屏/触笔）人工验证**。
jsdom 会话级模拟已由 vitest 覆盖（dragSession 状态机/pointer 键控集合/watchdog 分场景锚——B4' 批）；
本协议补「真机事件序列与 UI 实态」的最后一公里。设备：任意 Windows 触屏笔记本/平板 + 可选触笔。

## 通用准备

1. 本地起 api+web，登录，打开一张含：普通组（带 2 子）+折叠组+分镜组+若干顶层节点的画布。
2. 每个用例若判定异常，记录：操作序列 / 期望 / 实际 / DevTools Console 报错（DEV 断言直抛——异常必须带 [C0 断言]/[O0b-*] 前缀日志）。

## 一、多指手势（D1/D2/D3/D4——风险台账编号）

| # | 步骤 | 预期 | 登记号 |
|---|------|------|--------|
| M1 | 单指按住子节点拖动中，第二指在 pane 上做 pinch 缩放 | **不缩放**（capture 抑制——session 期间 pane pinch 不发生）；拖动正常 | D1 |
| M2 | 无手势时双指 pinch | 正常缩放（抑制只作用于 session 期间） | D1 对照 |
| M3 | 单指按住子节点拖动中，第二指点按另一节点 | 拖动不中断、不跳变（多指以首指为准——活动指针键控集合按 pointerId 移除） | — |
| M4 | 先在节点 A 按下（外容器），未松开再按下节点 B（内容器）——「先外后内」 | 现状 abort 静默维持（手势丢弃，无半拖态残留） | D2 |
| M5 | 双指按住后**先松第二指**（触发 handle 菜单路径的场景） | 菜单坐标以第二指为准（已知错位登记——验收为「与登记相符」非阻断） | D4 |
| M6 | 拖动选择框（marquee）期间 pinch | marquee 不中断（marquee guard 通道与节点拖动分立） | — |
| M7 | overlay（裁剪/框选浮层）拖动中把指针移到空白处继续 | 不出现「拖空白移旧集」症状（dragItems 闭包复用假想项——对号验证） | D3 |

## 二、capture 抑制/指针丢失自愈（D5）

| # | 步骤 | 预期 | 登记号 |
|---|------|------|--------|
| C1 | 触笔拖动子节点，拖动中把笔移出感应范围（pointerup 丢失形态） | 下一次任何 begin 手势时旧 session 无条件丢弃；节点无半拖态（松手补丁不残留） | D5 |
| C2 | 拖动中 Alt+Tab 切走再切回（blur 后窗口） | 同 C1：切回后画布无卡住的拖动态；节点位置=松手前最后 doc 值或拖前值（无中间漂移） | D5 |
| C3 | 拖动中直接关标签页再重开 | 重开后位置=拖前值（手势期 doc 零写）；另一端无跳变（e2e T8 已覆盖——真机对号） | — |
| C4 | pen/mouse 无取消事件场景：拖动中按 Esc | 拖动取消、节点回拖前位（Esc 取消链——capture 抑制不含 touchcancel 的补偿面） | — |

## 三、watchdog（会话超时终结）

| # | 步骤 | 预期 | 登记号 |
|---|------|------|--------|
| W1 | 单指按住节点**完全静止**超过 watchdog 时限（现值见 dragSession.lastActivityAt 常量） | watchdog 终结 session（cs 停末帧=设计内）；无 Console 报错（canEdit 守卫下 DEV invariant 不抛） | — |
| W2 | W1 后立即再拖同一节点 | 新 session 正常开启（watchdog 终结后无「锁死」） | — |
| W3 | resize 组手势中静止超时 | 同 W1（resizeTargetId 档）；组停在预览帧值，无半 resize 态 | — |

## 四、+号/批量连线触摸面（需求 6/7 触屏档）

| # | 步骤 | 预期 |
|---|------|------|
| P1 | 触屏单选组→+号出现 | +号可触点（40×56 命中区大于视觉 24px 圆——手指可命中） |
| P2 | 从 +号滑线到目标节点松指 | 批量连线生成（触屏拖线与鼠标同链路） |
| P3 | 0.5×/2× 缩放下重复 P1/P2 | 屏幕恒定尺寸/可点性不变（e2e T11 已覆盖鼠标档——真机补触摸命中） |

## 判定与回写

- 全部「与登记相符」或符合预期 → 真机面验收通过；异常项回写 spec §5 对应登记行（带实测序列）。
- 本协议不进 CI；重跑成本=30 分钟人工，版本大变更（手势内核/dragSession 结构改动）后建议重跑一/二节。
